# AI Lead Intelligence — UI mockups

Standalone HTML (inline CSS + tiny JS). Open any file in a browser — no build.

**Palette:** SaaSquatch dark system (`#121826` base, `#1A2236` / `#232B3E` panels, teal `#14B8A6` / `#2DD4BF`, blue `#3B82F6`).

| File | One-line tradeoff |
|------|-------------------|
| `01-split-workspace.html` | **A** — 3-pane ops console: always-on detail, but left rail costs width. |
| `02-command-center.html` | **B** — Max density Bloomberg layout; best data/pixel, steepest learning curve. |
| `03-canvas-cards.html` | **C** — Card masonry + modal detail; easiest scan, weakest for numeric sort/compare. |
| `04-hybrid-a-cards.html` | **Hybrid A+C** — A's chrome + drawer with C-style cards, triple metric rings, page-size control. |

All mockups share the same fake product data (Adept AI + Boston Dynamics refs, Ideal DNA strip, ranked leads with scores/confidence/recommendations/AI badges/evidence).

Label on each page: **Mockup A/B/C / Hybrid A+C — pick one**.
